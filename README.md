Official public release downloads for [Aion](https://aion.7caifei.com/), a macOS app.

This repository contains release packages and download metadata only. It does not
contain the Aion application source code.

## Download

Visit [Releases](https://github.com/monkey-sking/aion-downloads/releases/latest)
to download the latest signed Aion installer. The current release is also
available directly from GitHub Pages:

[Aion 2.12.25](https://monkey-sking.github.io/aion-downloads/Aion_2.12.25_manual.dmg)

## Verify a download

Each release lists the SHA-256 checksum. On macOS, verify a downloaded package
with:

```sh
shasum -a 256 /path/to/Aion.dmg
```
